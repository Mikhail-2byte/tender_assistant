# Журнал пробной работы

Используйте этот файл для замечаний о собственной установке. Проверяйте изменения на отдельной базе и сохраняйте резервные копии.

Для каждого случая укажите версию приложения, действия, ожидаемый и фактический результат. Перед отправкой журнала исключите реальные номера тендеров, контакты, тексты документов и ключи доступа.

Внутренний журнал исходной установки не публикуется.

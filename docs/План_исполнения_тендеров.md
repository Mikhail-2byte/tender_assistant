# Исполнение тендеров

Приложение связывает тендеры, договоры, спецификации и позиции. Реестр исполнения показывает группы «В работе» и «Поставлены». Количества, сроки и комментарии сохраняются в SQLite. Неизвестные значения требуют проверки пользователем.

Следующий шаг — пользовательская приёмка поиска, импорта и работы с площадками на отдельной базе с резервной копией.

Публичная версия документа не содержит исходных рабочих таблиц и истории их переноса.

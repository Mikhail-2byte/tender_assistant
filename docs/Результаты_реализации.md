# Публичная версия проекта

Опубликованы текущие исходники приложения, тесты, средства сборки и вымышленные примеры. Для тестов создана отдельная база из 237 искусственных записей. Обычный первый запуск создаёт четыре демонстрационных тендера и четыре спецификации.

Рабочие базы, Excel, документы, настройки доступа, внутренние отчёты и прежняя локальная Git-история в публикацию не включены. Они остаются в исходном локальном проекте.

Следующий этап — пользовательская приёмка поиска, импорта и загрузки документов с площадок. Результат автоматических проверок этой публикации указан в описании коммита.

Проверка публикации: 837 тестов в 58 изолированных модулях прошли. В двух модулях тестовые сценарии адаптированы к вымышленным данным и проверены повторно. Код приложения сохранён; удалена одна лишняя пустая строка в конце файла.

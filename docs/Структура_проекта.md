# Структура проекта

- `tender_app/` — Python-код, интерфейс и ресурсы.
- `tests/` — pytest-проверки; Qt работает в режиме offscreen.
- `scripts/` — сборка portable, диагностика, импорт и проверки.
- `data/sample/` — схема SQLite и полностью вымышленная тестовая база.
- `data/source/` — локальные исходники импорта, исключённые из Git.
- `artifacts/`, `build/`, `dist/` — локальные результаты и рабочие данные, исключённые из Git.

Главная точка запуска — `run_execution.py`. Исторические корневые команды запуска используют то же приложение. Новые проверки сохраняйте в `artifacts/checks/`.

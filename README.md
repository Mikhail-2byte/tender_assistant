# tender_assistant

Локальное Windows-приложение для реестра тендеров, исполнения договоров и работы с AI-помощником. Python, PySide6 и SQLite.

В одном окне доступны реестр, карточки, спецификации, позиции, комментарии и поиск. Поддерживаются загрузка из Excel, импорт из 1С, резервные копии и получение документов с площадок. Основная работа с сохранёнными данными доступна без интернета. Для AI и площадок нужны собственные настройки доступа.

## Установка и запуск

В PowerShell из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe run_execution.py
```

При первом запуске создаются четыре вымышленных тендера и четыре спецификации. Рабочая база и настройки хранятся локально в `artifacts/execution-preview-data/`.

Отдельная пробная база:

```powershell
.\.venv\Scripts\python.exe run_execution.py --data-dir artifacts/trial
```

Меню «Настройки → База данных» позволяет сохранить Excel-шаблон, проверить загрузку и создать собственную базу. Ключи AI и доступы к площадкам вводятся в приложении; секреты хранятся отдельно в Windows.

## Проверка и сборка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
powershell -ExecutionPolicy Bypass -File scripts/build_portable.ps1
.\.venv\Scripts\python.exe scripts/verify_portable.py
```

Для изолированного прогона каждого тестового модуля:

```powershell
.\.venv\Scripts\python.exe scripts/check_test_modules.py artifacts/checks/tests
```

Portable хранит свои данные рядом с исполняемым файлом. Перед пересборкой закройте приложение.

## Состав репозитория

- `tender_app/` — приложение и ресурсы.
- `tests/` — автоматические проверки.
- `scripts/` — сборка, диагностика и служебные команды.
- `data/sample/` — схема SQLite и полностью вымышленная тестовая база из 237 записей.

Публикация содержит текущий код без прежней локальной Git-истории. Исходные Excel, реальные базы тендеров, документы, настройки, ключи, резервные копии и внутренние отчёты сюда не включены.

Следующий этап разработки — пользовательская приёмка поиска, импорта и загрузки документов с площадок на отдельно подготовленных данных.

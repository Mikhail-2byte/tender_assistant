# Вымышленные тестовые данные

`tenders.db` содержит 237 полностью вымышленных записей для автоматических тестов. Одна запись намеренно не имеет номера для проверки сохранения старых импортов. Названия, номера, контакты, сроки и комментарии созданы программно. Это не выгрузка рабочей базы.

Обычный запуск приложения в новой папке отдельно создаёт четыре демонстрационных тендера и четыре спецификации.
